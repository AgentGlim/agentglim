Model icons drawn for 16 pixels

The dashboard shows these icons at 16 px, so every option here was drawn for that size and checked in screenshots at real size.

Each model gets its own version of the brand mark. Sonnet (six even rays), Haiku (a pinwheel) and Sol (a sun inside the orbits) are set. Fable, Opus, Terra, Astra and Luna each have a few versions to choose from.

Pick one icon per model. Every option shows its real 16 px size in a dashboard-style row, plus the dimmed copy the dashboard shows for paused runs.

Icons follow the model name, not the route. Opus looks the same on the Claude sub, an API key or OpenRouter.

New models

When the run starts using a model it hasn't seen before, AgentGlim makes its icon for you.

  1. New version, same tier. claude-opus-6 or gpt-6.2-sol reuses the Opus or Sol icon. Nothing new is made.
  2. New tier. A new name gets its own logo version, picked from its name: mini, flash or nano get the fast versions, pro, max or ultra the strong ones, code or dev the worker ones, and anything else the balanced ones. It takes the first version no other model in the brand uses.
  3. Saved on first sight. The server stores it in data/model-icons.json so it never shifts. It appears on this page with a Rule tag, so you can change it.
  4. Change your mind any time. If your most-used style for a brand changes, the auto-made icons switch to it too. Your own picks never change.
  5. No picks yet? That brand keeps its plain mark until you pick at least one model.
