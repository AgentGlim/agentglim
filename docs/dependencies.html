What AgentGlim needs outside its repo

This report lists the code's external dependencies only. It records no detection results, no machine inventory and no local paths: run node dev/build-dependencies.mjs for a report of your own machine. Your accounts, keys, projects, logs and installed personal skills remain on your machine.

What ships in the installer

Ship the app, generic project skills, and the small notification, routing and tracking scripts. These are source resources under the project license. They are now included in desktop staging. The six bundled skills are setup, design-all, page-update, plan-status-page, theme and humanizer. Personal global or plugin skills are never staged.

A platform-specific Node runtime can be bundled as a signed sidecar with its license and third-party notices. The current installer still discovers an installed Node 22.13+; this change does not pretend to include a runtime. Tauri itself is MIT/Apache-2.0. The OS webview remains a platform dependency: WebKitGTK on Linux, WKWebView on macOS, WebView2 on Windows.

Keep Chromium/Playwright, Python, harness CLIs, local model servers and model weights, Tailscale, FFmpeg and the plans driver optional. They are large, platform-specific, frequently updated, separately licensed, require login, or are unnecessary for the basic dashboard. Some open-source binaries can legally be redistributed with notices/source obligations, but bundling them would add installer size and maintenance. Proprietary CLIs, credentials, profiles, service accounts, private plans and personal skill libraries must not be copied into an installer.

Run npm run install-addons to add command links or Windows wrappers. It preserves existing commands and skills, and does not download tools automatically. Missing optional components show what is lost and how to install them on Setup. The built-in poller, daily price checker and process guard have no model-call dependency.

Privacy changes and limits of this audit

The release started with zero privacy-check findings. Imported source hits were addressed in tools/addons/jev-gate (ROUTER, CWD, TRACK, LOG, CACHE) and tools/addons/jobs-track.py (DIR, MAP_FILE and default-directory checks). All became repo-relative or configured private-data roots. The former tracker fixture plan identifier became a generic example. New adapters replaced fixed home-folder paths in the notification/routing/tracking imports with configured or private-data roots. Removed the dashboard's baked-in subscription history and automatic custom-project guesses. Replaced the Skill Editor redirect with a machine-local read-only skill inventory. Replaced plans-backed work-directory selection with private-data defaults. The generic project skills use relative paths, app configuration and the bundled dark theme.

Legacy local backups, archives and personal skill folders remain ignored and preserved; they are not release artifacts. The desktop stager excludes backups, tests, profiles, runtime data, the legacy Skill Editor and non-public harness glue. The final privacy check and fresh-HOME/browser tests are recorded in the implementation handoff.
